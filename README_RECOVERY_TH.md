# ชุดกู้คืนระบบ Workforce

## ไฟล์ที่ต้องแทนที่ใน GitHub
คัดลอกไฟล์ 3 ไฟล์นี้ไปแทนไฟล์ชื่อเดียวกันที่โฟลเดอร์หลักของ repository:
- `index.html`
- `script.js`
- `opd2-data-store.js`

จากนั้น commit การเปลี่ยนแปลงและรอ GitHub Pages deploy เสร็จ ไม่ต้องแก้ `Code.gs` หรือ `Bridge.html` สำหรับชุดแก้นี้

## สิ่งที่แก้
- หน้าเลือกหน่วย/ห้องและตารางจ่ายงานโหลดทันที ไม่รอ Google Apps Script
- หากเชื่อมต่อช้า หน้าเว็บยังใช้งานได้ และการเพิ่ม/แก้รายชื่อระหว่างรอจะเก็บในเบราว์เซอร์ก่อน แล้วส่งขึ้นชีตเมื่อเชื่อมต่อสำเร็จ
- ถ้า Google Sheet ยังไม่มีรายชื่อ ระบบจะรักษารายชื่อ/Default ที่มีอยู่ใน localStorage ของเบราว์เซอร์และนำขึ้นชีต แทนการเขียนทับด้วยรายการว่าง
- ถ้า Google Sheets เชื่อมต่อไม่ได้ แถบสถานะจะแจ้งปัญหา แต่ไม่ทำให้ทั้งระบบหยุดทำงาน

## ขอบเขตการซิงก์ปัจจุบัน
รายชื่อเจ้าหน้าที่และค่า Default ซิงก์ผ่าน Google Sheets ส่วนแผนผู้ป่วยและการจ่ายงานรายสัปดาห์ยังเก็บในเบราว์เซอร์เครื่องนั้น ไม่ได้ซิงก์ข้ามเครื่องในชุดแก้นี้
