Local Storage
เริ่มใช้งานทีละขั้น
01

เลือกหน่วยตรวจ ห้องตรวจ และสัปดาห์

เริ่มจากตัวเลือกด้านบนของหน้า ระบบแยกข้อมูลตามหน่วยตรวจและห้องตรวจที่เลือก

  • เลือกสัปดาห์ด้วยปุ่มวันที่ แล้วเลือกจากปฏิทิน หรือใช้ “สัปดาห์ก่อน/ถัดไป”
  • แผนเริ่มต้นเป็นวันจันทร์–ศุกร์; เลือกพื้นที่ให้ถูกก่อนกรอกข้อมูล
02

กรอกแผนผู้รับบริการรายวัน

ใน “แผนผู้รับบริการรายวัน” ใส่จำนวนแยกประเภทในแต่ละวัน

  • นัดหมายWalk-inนอกระบบ
  • ระบบรวมยอดให้อัตโนมัติ; กด “ตั้งเป็นวันหยุด” เพื่อไม่นำวันนั้นไปคำนวณ
03

เพิ่มรายชื่อทีมในพื้นที่

ไปที่ “จัดการเจ้าหน้าที่” เพิ่มด้วยชื่อสมมติและตำแหน่ง

  • ตำแหน่งที่รองรับ: HNInchargeRNPNHP
  • ใช้ “แก้ไข” เปลี่ยนชื่อ/ตำแหน่งได้โดยไม่ต้องลบ; กด “ลบ” เมื่อต้องการนำชื่อออก
  • รายชื่อแยกตามหน่วย/ห้องตรวจ; เพิ่มทีมแยกกันในแต่ละพื้นที่
04

จ่ายงานและสถานะรายวัน

เลือกวันใน “ตารางจ่ายงานรายบุคคล” แล้วตั้งข้อมูลของเจ้าหน้าที่แต่ละคน

  • เลือกสถานะ ปฏิบัติงานVAC = ลาประชุม/อบรมFloat ออกใช้ ชม.
  • เลือกหน้าที่/เวลา (พิมพ์ช่วงเช่น 8-12), เวลาพัก, ปภ.1/2, Code อัคคีภัย/CPR, เวลาเข้าและหมายเหตุ
  • “เพิ่มหน้าที่” เพิ่มรายการ; “ใช้ Default” นำรูปแบบที่บันทึกล่าสุดมาใช้กับวันนั้น

▦ดูภาพรวม บันทึก และส่งออก

  • Dashboard สรุปทุกหน่วยตรวจ ดูภาพรวมแต่ละห้องและกด “Detail +” เพื่อขยายรายละเอียด
  • ดูรายงาน เปิดสรุป Product รายวันและจำนวนวันที่อยู่ใน/นอกเกณฑ์
